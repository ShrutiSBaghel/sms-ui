### Instructions

For any new component use 'ng g c {component_name}' this will create a standalone component folder with component.ts, css, spec.ts files.
Keep app.ts as it is, don't add new component in there always create a new one.
For any new service to be added use 'ng g s {service_name}'.
Any business logic is to be added in the service corresponding to the component.
Make use of signals if and when required.
Don't make any changes in the file until I apporve them.
